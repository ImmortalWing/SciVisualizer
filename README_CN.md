# SciVisualizer - 科学数据可视化分析工具

## 概述
SciVisualizer是一个基于Python的综合科学数据可视化和分析工具。采用PySide6和Qt框架开发，提供直观的图形界面用于各种科学计算任务。

## 主要功能

### 数据分析
- **D-S证据理论**：多源证据融合
- **主成分分析(PCA)**：数据降维
- **因子分析**：识别数据集中的潜在变量
- 基于matplotlib的交互式数据可视化

### 机器学习
- 支持向量机(SVM)
- 随机森林算法
- 极限学习机(ELM)
- 径向基函数网络(RBF)

### 专业模块
- 裂隙识别与分析
- 深度学习集成
- 数据采集与处理工具

## 安装指南
1. 确保已安装Python 3.8+
2. 安装依赖项：
```bash
pip install -r requirements.txt
```

## 使用说明

### 快速开始
1. 运行应用程序：
```bash
python main.py
```

2. 主界面组件：
- 模块选择导航栏
- 数据可视化区域
- 分析控制面板
- 结果显示区

### 数据分析流程
1. 加载数据集(推荐CSV格式)
2. 选择分析方法：
   - D-S证据理论
   - 主成分分析
   - 因子分析
3. 在表格和交互式图表中查看结果
4. 按需导出结果

### 机器学习流程
1. 准备数据集
2. 选择机器学习算法
3. 配置参数
4. 训练并评估模型
5. 可视化结果
